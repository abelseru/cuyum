# Convención de idioma de Cuyum 1.3

Cuyum usa inglés para el código interno y español para la presentación pública.

## Inglés interno

- nombres de archivos
- nombres de funciones
- variables
- constantes
- claves técnicas internas
- modos del sistema
- logs técnicos

## Español público

- interfaz web
- textos para usuarios
- documentación escolar
- etiquetas humanas de estado
- explicaciones de eventos
