# Hotfix mapa SVG territorial

Reemplaza el mapa esquemático tipo radar por un SVG fijo con base territorial simplificada.

- No usa Leaflet.
- No usa tiles externos.
- No tiene zoom ni navegación.
- Sigue usando un solo JSON público por ciclo: /api/public/live.
- Dibuja sensores, células y una base de países simplificada para la cobertura actual.

La base cartográfica es liviana y puede ampliarse en futuras versiones para más regiones del mundo.
